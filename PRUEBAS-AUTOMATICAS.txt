PUNTO YA CR · PRUEBAS AUTOMÁTICAS

GitHub Actions ejecuta Playwright automáticamente al hacer push a main o manualmente desde Actions.

Pruebas incluidas:
- PC: Chromium
- iPhone: WebKit
- Tablet: WebKit
- Web pública
- Panel público/sin sesión
- Acciones públicas
- Pruebas agresivas
- Seguridad/RLS (solo si se configuran cuentas de prueba)

Comandos locales si tienes Node instalado:
  npm install
  npx playwright install chromium webkit
  npm run test:web

Pruebas separadas:
  npm run test:smoke
  npm run test:aggressive
  npm run test:security

GitHub Secrets opcionales para seguridad real:
  SUPABASE_URL
  SUPABASE_ANON_KEY
  TEST_A_EMAIL
  TEST_A_PASSWORD
  TEST_B_EMAIL
  TEST_B_PASSWORD
  TEST_ROLE_EMAIL
  TEST_ROLE_PASSWORD

Recomendación de cuentas:
- TEST_A: dueño de un negocio FREE exclusivamente de pruebas.
- TEST_B: dueño de otro negocio distinto exclusivamente de pruebas.
- TEST_ROLE: Caja/Cocina u otro miembro no-owner de un negocio de pruebas.

Nunca uses las credenciales del negocio real en GitHub Secrets de pruebas.
El reporte HTML se guarda como artifact “reporte-playwright-punto-ya-cr”.
