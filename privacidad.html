Política de Privacidad

Versión 2026.09 · Última actualización: 22 de septiembre de 2026.

Pendiente antes del lanzamiento comercial: completar la identidad jurídica del responsable, domicilio y correo oficial para el ejercicio de derechos.
En palabras simplesUsamos la información necesaria para crear cuentas, operar negocios, proteger la plataforma y prestar las funciones que el usuario activa. No vendemos bases de datos personales.

1. Qué información puede tratarse

Según las funciones utilizadas, PUNTO YA CR puede tratar datos de cuenta y autenticación; nombre y datos del negocio; configuraciones; productos e inventario; ventas y comprobantes; clientes; cuentas por cobrar; proveedores; compras y gastos; usuarios y roles; información de soporte; suscripciones, códigos PRO y comunicaciones; así como logos y otros archivos cargados por el negocio.

2. Finalidades

La información se utiliza para autenticar, prestar y sincronizar el servicio; gestionar permisos; generar reportes; brindar soporte; mantener seguridad y auditoría; administrar planes y activaciones; atender solicitudes legales y de privacidad; y enviar novedades únicamente cuando exista una suscripción voluntaria.

3. PUNTO YA CR como responsable y como encargado

PUNTO YA CR actúa como responsable respecto de información necesaria para administrar su propia relación con usuarios, seguridad, soporte, comunicaciones y suscripción. Cuando un negocio utiliza la plataforma para almacenar datos de sus clientes, proveedores, personal u otros terceros, PUNTO YA CR puede actuar como proveedor o encargado tecnológico por cuenta de ese negocio, conforme al Acuerdo de Tratamiento de Datos.

4. Logos y archivos visibles

Los logos del negocio pueden almacenarse de forma que resulten accesibles mediante una URL pública cuando la función requiera mostrarlos en reportes, documentos, catálogos u otras superficies visibles. No debe utilizarse el mismo esquema para documentos que el negocio espere mantener privados.

5. Proveedores tecnológicos

PUNTO YA CR utiliza proveedores tecnológicos para alojamiento, distribución web, autenticación, base de datos y almacenamiento. La lista vigente y la función de cada proveedor se publica en Proveedores tecnológicos.

6. Conservación

Los datos no deben conservarse indefinidamente sin finalidad. PUNTO YA CR definirá periodos de conservación por categoría, considerando la relación contractual, seguridad, obligaciones legales, respaldo, resolución de disputas y solicitudes de eliminación. La eliminación de una cuenta no implica necesariamente borrar de inmediato información cuya conservación sea obligatoria o necesaria por una base legítima.

7. Seguridad

Se aplican controles de autenticación, permisos, separación lógica entre negocios y otras medidas técnicas y organizativas razonables. Ningún sistema puede garantizar riesgo cero. Los incidentes se gestionarán mediante un procedimiento interno y, cuando corresponda, se efectuarán las comunicaciones legalmente exigibles.

8. Derechos

Las personas titulares pueden ejercer los derechos que la legislación costarricense les reconozca, incluyendo acceso, rectificación y supresión cuando proceda. PUNTO YA CR mantendrá un canal para registrar la solicitud, verificar identidad, documentar la respuesta y cumplir los plazos aplicables.

PRODHAB indica, entre otros supuestos, un plazo de cinco días hábiles para atender determinadas solicitudes de rectificación y establece deberes de información frente a vulneraciones de seguridad.

Base legal: Ley N.° 8968 y Reglamento N.° 37554-JP. Referencia oficial: PRODHAB – Preguntas frecuentes.

9. Newsletter y comunicaciones

La suscripción a novedades es voluntaria. El correo se utiliza para la finalidad informada y debe existir una vía sencilla para dejar de recibir comunicaciones. En la versión definitiva se conservará evidencia de fecha, origen y versión del consentimiento.

10. Menores

PUNTO YA CR está orientado a personas con capacidad para administrar o representar negocios. No está diseñado como un servicio dirigido a menores de edad.

11. Cambios

Las modificaciones materiales se identificarán mediante número de versión y fecha. Cuando un cambio requiera consentimiento adicional, se solicitará de forma expresa.
