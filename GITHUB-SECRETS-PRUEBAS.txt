PUNTO YA CR · GITHUB SECRETS PARA PRUEBAS DE SEGURIDAD

Configurar solo cuando existan cuentas EXCLUSIVAS DE PRUEBA.
GitHub → Settings → Secrets and variables → Actions → New repository secret.

SUPABASE_URL        URL pública del proyecto Supabase.
SUPABASE_ANON_KEY   Publishable/anon key pública (nunca service_role).
TEST_A_EMAIL        Dueño de Negocio A de prueba, idealmente FREE.
TEST_A_PASSWORD     Contraseña de esa cuenta de prueba.
TEST_B_EMAIL        Dueño de Negocio B distinto.
TEST_B_PASSWORD     Contraseña de esa cuenta de prueba.
TEST_ROLE_EMAIL     Usuario Caja/Cocina/no-owner de prueba.
TEST_ROLE_PASSWORD  Contraseña de ese usuario de prueba.

NO poner en GitHub:
- service_role
- contraseñas de cuentas reales
- claves fiscales
- llaves de facturación electrónica
- secretos de futuras pasarelas de pago
