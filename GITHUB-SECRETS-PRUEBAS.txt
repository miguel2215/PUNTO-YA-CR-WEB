PUNTO YA CR — GitHub Secrets para pruebas reales

Settings > Secrets and variables > Actions > New repository secret

Obligatorios para RLS / aislamiento:
SUPABASE_URL
SUPABASE_ANON_KEY
TEST_A_EMAIL
TEST_A_PASSWORD
TEST_B_EMAIL
TEST_B_PASSWORD
TEST_ROLE_EMAIL
TEST_ROLE_PASSWORD

Estructura recomendada:
- TEST_A: propietario de un negocio de prueba FREE.
- TEST_B: propietario de OTRO negocio de prueba. Idealmente PRO para probar todo el Panel.
- TEST_ROLE: Caja/Cocina u otro miembro NO propietario del negocio de prueba.

Opcional para pruebas que escriben temporalmente datos desde la interfaz:
TEST_WRITE_MODE=true

IMPORTANTE:
- Usa únicamente negocios/cuentas creados para pruebas.
- Nunca uses un negocio real de producción para TEST_WRITE_MODE.
- La prueba de escritura modifica temporalmente el teléfono del negocio TEST_B y lo restaura al terminar.
- Las pruebas de seguridad A/B no crean ni borran datos.
